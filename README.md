# NEXUS MATCHLINK

Уведомитель о матче для **Dota 2** и **CS2**: следит за экраном и, когда
появляется кнопка **Accept**, мгновенно присылает уведомление в **Telegram**
и играет **звуковой сигнал** — чтобы вы успели вернуться к компу.

Мульти-игровая платформа: каждая игра добавляется как отдельный профиль
(шаблон кнопки + как найти её окно). Список растёт постепенно.

> **Официальный канал релизов:** [t.me/nexus_matchlink](https://t.me/nexus_matchlink)
> — там всегда свежий `.exe`, инструкции и новости.

## Возможности

- Непрерывный мониторинг экрана (кнопка Accept определяется по эталонному изображению).
- Уведомления в Telegram (бот) + звуковой сигнал.
- **Удалённый приём матча:** в сообщении о найденном матче есть кнопка
  **«ПРИНЯТЬ МАТЧ»** — нажмите её в телефоне, и программа сама кликнет Accept за вас.
- **Команды бота** из Telegram: `/status`, `/stats`, `/accept`, `/test`,
  `/version`, `/help` — статус и статистика доступны удалённо.
- **Статистика матчей:** найдено / принято / упущено + время последнего матча
  (в интерфейсе и по команде `/stats`).
- Игру можно сворачивать: программа сама развернёт окно и выведет его на передний план.
- Мульти-игра: **Dota 2** и **CS2** уже в реестре, выбор в один клик.
- Подключение своего Telegram в один клик, прямо из программы.
- Тумблеры **звука** и **скриншота в уведомлениях** прямо в интерфейсе.
- Киберпанк-интерфейс с обоями.
- Работает из собранного `.exe` без установки Python.

## English quick start

1. Download the release `.exe` from [t.me/nexus_matchlink](https://t.me/nexus_matchlink).
2. Run it, pick your game (Dota 2 / CS2), start the game and queue up.
3. Press **START**.
4. When the Accept button appears you get a Telegram push with a
   **«ПРИНЯТЬ МАТЧ»** button — tap it on your phone and the app clicks Accept for you.
5. First run: press **CONNECT TG**, send the 6-digit code to the bot to link your Telegram.

## Быстрый старт (готовый .exe)

1. Скачайте `dist/NexusMatchlink.exe`.
2. Запустите двойным кликом.
3. Выберите игру в списке (Dota 2 / CS2), запустите её и встаньте в поиск матча.
4. Нажмите **START**.
5. Когда появится кнопка Accept — приложение сообщит (звук + Telegram)
   и пришлёт кнопку **«ПРИНЯТЬ МАТЧ»**.
6. Нажмите её в Telegram — матч будет принят автоматически.

### Удалённый приём матча

- Игра должна быть запущена — **сворачивать её можно**, программа сама
  развернёт окно и выведет его на передний план перед кликом.
- Кнопку надо нажать, пока висит окно принятия (30–45 секунд).
- Результат приходит в Telegram: подтверждение или причина отказа.

### Первое подключение Telegram

1. Нажмите кнопку **CONNECT TG**.
2. В окне появится **код** (6 цифр) и имя бота.
3. В Telegram найдите этого бота и отправьте ему этот код одним сообщением
   (кнопка **КОПИРОВАТЬ** рядом с кодом — чтобы не печатать вручную).
4. Программа сама определит ваш `chat_id` и сохранит его — больше ничего настраивать не нужно.

Имя бота (display name) совпадает с приложением — **Nexus Matchlink**.
Если бот в Telegram ещё называется иначе, переименуйте его через
**BotFather**: `/setname` → выберите бота → `Nexus Matchlink`.
Юзернейм (`@lerrus_dota_notifier_bot`) поменять нельзя — это постоянный
идентификатор бота.

В боте ответы при удалённом приёме указывают выбранную игру
(«Матч CS2 принят!», «Матч Dota 2 принят!») — уведомления одинаково
корректны для обеих игр.

### Команды бота

Бот отвечает в личном чате с вами (пока приложение запущено):

| Команда | Что делает |
| --- | --- |
| `/status` | Статус мониторинга: активен ли, какая игра, аптайм |
| `/stats` | Статистика: найдено / принято / упущено, последний матч |
| `/accept` | Принять текущий матч (аналог кнопки «ПРИНЯТЬ МАТЧ») |
| `/test` | Отправить тестовое уведомление |
| `/version` | Версия приложения |
| `/help` | Справка по командам |

Статистика хранится в `stats.json` рядом с `.exe` и переживает перезапуски.

Настройки хранятся в файле `config/settings.json` рядом с `.exe` —
у каждого пользователя свои.

## Поддержка CS2

Профиль **CS2** уже в реестре (поиск окна по заголовку `counter-strike`,
процесс `cs2.exe`). Остался только один шаг — **шаблон кнопки**:

1. Запустите CS2 и дождитесь экрана принятия матча.
2. Сделайте скриншот (Win+Shift+S) и вырежьте кнопку **ACCEPT**.
3. Сохраните как `images/accept_cs2.png` рядом с программой.
4. Выберите **CS2** в программе и нажмите START.

Скриншот делается на **любом** разрешении: программа автоматически
подбирает масштаб кнопки под ваш экран (диапазон 0.5x–2.5x). Если
разрешение меняется — переснимать шаблон не нужно.

Пока файла нет, при выборе CS2 программа покажет понятное сообщение
вместо молчаливой ошибки.

## Запуск из исходников

Требуется Python 3.12+ и Windows.

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
NexusMatchlink.bat
```

`NexusMatchlink.bat` запускает интерфейс без консольного окна.

## Сборка .exe

```bat
build_exe.bat
```

Результат: `dist/NexusMatchlink.exe` (single file, без консоли, ~30 МБ).

## Как это устроено

```
DotaMatchNotifier/
├── gui_main.py              # точка входа интерфейса
├── config/                  # загрузка/сохранение настроек (несколько игр)
│   ├── settings.json        # личные настройки (в git не хранятся)
│   └── settings.template.json  # чистый шаблон для сборки .exe
├── detector/                # поиск кнопки на экране (numpy + PIL, без OpenCV)
├── core/                    # фоновый мониторинг, логирование, клик мышью
├── notifier/                # каналы уведомлений: Telegram, звук
├── gui/                     # интерфейс CustomTkinter + диалог подключения TG
├── assets/                  # тема интерфейса, обои
└── images/                  # шаблоны кнопок Accept (accept.png, accept_cs2.png)
```

## Структура файла настроек

```json
{
  "selected_game": "Dota 2",
  "games": {
    "Dota 2": {
      "image_path": "images/accept.png",
      "confidence": 0.7,
      "search_region": null,
      "window_hints": ["dota 2"],
      "exe_hints": ["dota2.exe"]
    },
    "CS2": {
      "image_path": "images/accept_cs2.png",
      "confidence": 0.7,
      "search_region": null,
      "window_hints": ["counter-strike"],
      "exe_hints": ["cs2.exe"]
    }
  },
  "check_interval": 1.0,
  "log_dir": "logs",
  "telegram": {
    "enabled": true,
    "bot_token": "...",
    "chat_id": 0,
    "accept_enabled": true
  },
  "sound": { "enabled": true, "repeats": 3 }
}
```

- `chat_id: 0` — Telegram не подключён (нажмите **CONNECT TG**).
- `accept_enabled` — показывать ли кнопку «ПРИНЯТЬ МАТЧ» в уведомлениях.
- `confidence` — порог совпадения (0.0–1.0), ниже программа «не видит» кнопку.
- `search_region` — область поиска `[x, y, w, h]`; `null` — весь экран.
- `window_hints` / `exe_hints` — фрагменты заголовка окна и имена процессов
  игры, по которым программа находит её окно для автоклика.
- `games` — реестр игр, каждая со своими настройками поиска и окна.

Чтобы добавить новую игру: скопируйте блок в `games`, замените путь к
шаблону кнопки и подсказки окна.

## Журнал и ошибки

- События пишутся в `logs/monitor.log` рядом с приложением.
- Если программа упала без окна — смотрите `logs/crash.log`.

## Частые вопросы

**Матч не определяется.**
Убедитесь, что игра в полноэкранном режиме (не свёрнута), окно не перекрыто.
Проверьте порог `confidence` в настройках: если слишком высокий, кнопка не
распознаётся; если слишком низкий — возможны ложные срабатывания.

**Выбрал игру, но START пишет «не найден шаблон».**
Для этой игры ещё не сохранён шаблон кнопки в `images/`. Сделайте скриншот
экрана принятия и вырежьте кнопку Accept (см. раздел «Поддержка CS:GO»).

**Не приходят уведомления в Telegram.**
Нажмите **CONNECT TG** и повторите подключение. Убедитесь, что отправляете код
именно тому боту, имя которого показано в окне.

**Двое подключили бота одновременно.**
Бот общий, а `getUpdates` работает для одного сеанса. Если коды не связываются —
просто подождите и повторите попытку.

**Нажал «ПРИНЯТЬ МАТЧ», но пришла ошибка.**
Программа смогла принять игру только если: мониторинг запущен (нажата **START**),
игра запущена и кнопка Accept ещё не исчезла. Игра при этом может быть свёрнута —
программа сама развернёт её окно. В остальных случаях придёт сообщение с причиной
(например, «кнопка уже исчезла»).
