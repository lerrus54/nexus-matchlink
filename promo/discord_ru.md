# Discord — как запостить без бана

Дискорд-сервера по Dota/CS обычно запрещают рекламу в общих чатах.
90% таких серверов имеют отдельный канал: `#self-promo`, `#promo`, `#tools`,
`#инструменты`, `#поделись-своим`. Ищи его и пости только туда.

## Шаблон для #self-promo

Сделал бесплатную утилиту для Dota 2 и CS2: следит за экраном, и когда
нашёлся матч — шлёт уведомление в Telegram. В уведомлении кнопка
«ПРИНЯТЬ МАТЧ»: тап на телефоне → программа сама кликает Accept.
Работает в фоне, окно игры можно сворачивать.

Скачать: t.me/nexus_matchlink
Исходники: [GitHub-ссылка]

Не чит: чистая UI-автоматизация, ничего в игру не инжектит.

## Тонкие правила
- Не пиши в #general и не рекламируй в лс пользователям — бан.
- Перед постингом прочитай правила канала (обычно `/rules`).
- Встречаешь модератора — будь дружелюбен, удали пост если попросят.

## Список типов мест
- Крупные паблики по Dota 2 и CS2 на русском и английском.
- Сервера «по поиску тиммейтов» (митмейкинг) — там все сидят в очереди.
- Сервера разработчиков утилит (иногда есть #showcase).
